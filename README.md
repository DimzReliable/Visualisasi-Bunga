# Visualisasi-Bunga
Untukmu Aulia Yunianti Kurniadi, bunga yang pertama kali kupersembahkan lewat baris-baris kode sederhana. Mungkin ia tak semeriah bunga yang tumbuh di taman, tetapi setiap kelopaknya menyimpan ketulusan. Semoga bunga ini menjadi pengingat bahwa ada sesuatu yang dibuat dengan waktu, perhatian, dan hati, khusus untukmu.
